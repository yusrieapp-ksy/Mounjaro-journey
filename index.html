Privacy & what leaves my phone

Nothing is sent in the background. A Content Security Policy limits this page to your own site and the library host (cdnjs) used to download the PDF reader. There are no analytics, trackers or ads.

Your data only leaves when you choose to: Backup export, Doctor summary share, CSV export, or a link you tap (such as a 3D scan link).

Your phone does download app updates from GitHub Pages, so GitHub can see that the app was opened. That request carries no health data.

Public repository notice: never commit exported .json backup files or Visbody PDFs to GitHub.
Suggested .gitignore (for a computer or GitHub Desktop)
# Never commit personal data
*[Bb]ackup*.json
VMT-PRIVATE-*
*.visbody.pdf
Body_*.pdf

The GitHub website uploader ignores .gitignore, so simply keep backups out of the files you upload.

App passcode & welcome

A privacy screen against casual snooping, not encryption. Anyone who can read this phone's storage could get around it, so keep using backups and your iPhone's own lock. The app is also blurred in the app switcher while a passcode is on.

Switching phones

Four steps. Your data moves with a backup file.

  1. 1. Export a backup

    On this phone tap Backup Now and choose Save to Files (iCloud Drive).

  2. 2. Open the app on the new iPhone

    Open the same app address in Safari, tap Share, then Add to Home Screen.

  3. 3. Import the backup

    In the installed app open Settings, tap Check / Import Backup, pick the file, then choose Replace Everything.

  4. 4. Check the record counts

    They should match what this phone has now:

Data lives per web address, so use exactly the same address on the new phone. Keep the backup file private.
